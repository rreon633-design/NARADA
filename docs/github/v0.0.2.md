# v0.0.2 — development release scope

This is the cumulative source update after the published v0.0.1 baseline (`7f85f262a5c225c98dbfad49cef66e4949a16dc5`). The original tag/release, previous failed campaigns and source handoffs are not rewritten.

## Included

1. **Repair 01:** connection/recovery, chat and workspace feedback repairs, without treating a saved pairing or local service as authenticated connectivity.
2. **Interface cleanup:** shorter labels and guidance on desktop and Android; explicit permissions and important failures stay visible.
3. **Quick pairing:** simpler QR-first setup and bounded foreground checks; trust/desktop approval and folder permissions are not bypassed.
4. **Sharing Stage 1:** ordinary-download duplicate/retry protections, honest checked-byte progress and finite accessible animation, plus a pure folder-reconciliation planner. The progress fill uses individual CSSOM property assignment, compatible with the unchanged restrictive desktop CSP, rather than an inline style attribute.

The release-specific changes also update application metadata and the create-only release policy; they do not change application IDs, storage/trust/protocol versions, dependency pins, compression quality, native security settings or size budgets.

## Not yet implemented

The approved goal remains automatic two-way exchange between explicitly chosen phone and desktop folders **while both apps are open**, preserving conflicting versions and never silently mirroring deletions. This release **does not enable that feature**.

The planner is side-effect-free: it neither enumerates live providers nor writes files. Versioned upload/write consent, durable links and common-base/provenance records, conflict-preserving execution, echo prevention, bounded reconciliation queues and both-app foreground authority remain to be integrated. The existing protected-copy refresh mechanism is not a substitute.

Ordinary private download limits stay at **64 MiB per file**, **four retained transfers / 128 MiB shared reservation**; attachments stay at **8 MiB plaintext**. These limits do not yet satisfy dozens–hundreds of arbitrary files up to 100 MB. Uncertain SAF/provider outcomes are not automatically duplicated. A dialog's frozen transfer arguments are not a durable journal across restart.

## Validation and publication

The pre-release sharing checkpoint recorded **1,023 fresh local passes** (22 domain + 490 connection + 65 real-agent interop + 317 Android app + 76 browser + 53 Node), with 0 lint errors / 0 warnings / 36 informational hints. That is a separate historical local campaign, not proof of the new release commit or installed Windows/Android behavior. Release metadata, CI gating and CSP regression changes receive their own checks.

Publication requires fresh, same-commit/run/attempt GitHub tooling, Linux, Windows, Android, API 29 and API 35 gates. Current minima include 490 connection, 317 app, 76 browser and 53 Node cases; no skipped/failed/missing evidence may be counted as success. The exact minified x86_64 APK must pass all 14 native cases on each emulator. Four ABI APKs and Windows installation/bootstrap are audited separately.

The main-release policy explicitly requests v0.0.2 while retaining the historical initial-tag field v0.0.1. The publisher checks the current main SHA, then creates the requested annotated tag only if absent; it uploads/verifies a draft and publishes a prerelease last. Existing tags/releases are never moved or overwritten. See the release's workflow link, `CI-RELEASE-EVIDENCE.json`, build reports and `SHA256SUMS.txt` for actual results and measured sizes; no sizes are predicted here.

## Open qualification gates

Physical ARM/Android and Windows devices, real LAN/firewall/provider interruptions, 16 KiB-page runtime, power loss/ENOSPC and hostile-provider stoppability, accessibility/tray behavior, installed upgrade/rollback continuity, production signing, independent security/license review and measured real-hardware resource use remain open. Hosted emulators and browser fixtures do not close these gates.
