This development prerelease includes the cumulative connection/chat/workspace repairs, interface cleanup, quick pairing, and sharing Stage 1 changes since v0.0.1.

- **Connection and chat:** clearer authenticated connection/recovery states, bidirectional chat handling and safer workspace/permission feedback. A saved pairing, scan or local agent alone does not mean Connected.
- **Simpler pairing:** QR-first guidance, fewer manual steps and bounded foreground connection checks. Desktop approval, identity verification and explicit folder grants remain required.
- **Cleaner interface:** shorter desktop and Android labels without removing consent, security or error information.
- **Sharing Stage 1:** authority-bound duplicate suppression for ordinary private downloads; up to two narrow transient retries within an accepted foreground run; clearer checked-byte progress and finite/reduced-motion-aware desktop animation. Progress rendering respects the desktop's existing restrictive content-security policy.
- **Original quality:** no image/video recompression. File integrity and publication receipts remain distinct from progress; uncertain provider writes are not automatically repeated as new work.

**Automatic two-way folder sync is not enabled.** The new reconciliation planner does not execute folder changes. Versioned write transport/consent, durable folder links and provenance, conflict-preserving execution, and the bounded foreground scheduler remain future work. Existing protected copies are not two-way folder sync.

Current limits remain **64 MiB per ordinary private download**, **four retained private transfers / 128 MiB shared reservation**, and **8 MiB plaintext per attachment**. This release does not claim the larger everyday workload is fully supported. Background/offline interruptions can still require an explicit Resume; no always-on/background synchronization is promised.

Android and desktop application versions are **0.7.1**, Android versionCode **8**; the Rust workspace remains **0.7.1**. The GitHub tag is **v0.0.2**. No protocol, trust-store or database reset is introduced, and v0.0.1 remains untouched.

**Installation safety:** Android uses a temporary CI signing certificate and Windows is unsigned. A new Android signer may prevent an in-place update despite the higher versionCode. **Never uninstall, clear data, reset trust or delete valued state to force an upgrade.** Use a separate disposable test profile/VM and synthetic data; signing continuity, installed-device upgrades and physical Windows/Android/LAN/provider behavior remain unqualified.
